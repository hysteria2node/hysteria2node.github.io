一、Shadowrocket简介与核心价值

Shadowrocket是一款专为iOS设备设计的智能代理工具，它不仅仅是一个简单的VPN应用，更是一个支持多种协议的全功能网络解决方案。与传统的VPN软件相比，Shadowrocket具有以下显著优势：

  1. 多协议支持：完美兼容SS、SSR、Vmess等多种主流代理协议，满足不同用户的需求。
  2. 智能路由：可根据规则自动选择代理或直连，实现精准流量控制。
  3. 性能优化：采用先进的网络加速技术，显著提升网络访问速度。
  4. 隐私保护：加密所有网络流量，防止数据泄露和网络监控。

二、Shadowrocket下载与安装指南

1. 下载前的准备工作

在开始下载前，请确保您的设备满足以下条件：
- 运行iOS 11.0或更高版本
- 拥有有效的Apple ID
- 设备存储空间充足（应用大小约20MB）

2. 详细下载步骤

由于地区限制，Shadowrocket在某些国家/地区的App Store可能无法直接获取。以下是三种可行的下载方式：

方法一：直接通过App Store下载
1. 打开iOS设备上的App Store
2. 点击右上角的搜索图标
3. 输入"Shadowrocket"进行搜索
4. 找到应用后点击"获取"按钮
5. 通过Face ID/Touch ID或输入密码确认下载

方法二：切换Apple ID地区
如果当前地区无法下载，您可以：
1. 退出当前Apple ID
2. 创建一个新的Apple ID，选择支持Shadowrocket的地区（如美国）
3. 登录新ID后重新搜索下载

方法三：通过第三方应用市场
部分第三方iOS应用市场也提供Shadowrocket的下载，但需注意安全性风险。

3. 安装后的初始设置

安装完成后，首次打开应用时，系统可能会提示"Shadowrocket想添加VPN配置"，请点击"允许"。这是正常操作，应用需要此权限来建立代理连接。

三、Shadowrocket基础使用教程

1. 界面概览

Shadowrocket的主界面设计简洁明了，主要分为以下几个区域：
- 顶部状态栏：显示当前连接状态和网络速度
- 服务器列表：显示已配置的所有服务器
- 底部工具栏：包含主页、配置、日志和设置四个主要功能

2. 添加第一个服务器配置

步骤一：获取服务器信息
在使用Shadowrocket前，您需要准备有效的服务器配置。这些信息通常包括：
- 服务器地址（IP或域名）
- 端口号
- 加密方式
- 密码（如有）
- 协议类型（SS/SSR/Vmess等）

这些信息可以从您的代理服务提供商处获取，或通过可信的分享渠道获得。

步骤二：手动添加服务器
1. 点击右上角的"+"按钮
2. 选择"手动输入"
3. 根据您的服务器信息填写相应字段：
- 类型：选择对应协议（如Shadowsocks）
- 服务器：输入服务器地址
- 端口：输入服务端口
- 密码：输入连接密码
- 加密方法：选择对应加密方式（如aes-256-gcm）
4. 点击"完成"保存配置

步骤三：通过URL导入配置（推荐）
许多服务商提供一键配置URL，导入方法更为简便：
1. 获取配置链接（通常以ss://或vmess://开头）
2. 在Shadowrocket中点击"+"→"从URL导入"
3. 粘贴链接并确认
4. 系统会自动解析并添加配置

3. 连接与断开服务器

添加配置后，连接服务器非常简单：
1. 在主界面的服务器列表中找到目标配置
2. 点击右侧的开关按钮
3. 首次连接时可能需要允许VPN配置，点击"允许"
4. 连接成功后，顶部状态栏会显示VPN图标，应用内会显示"Connected"

要断开连接，只需再次点击同一开关按钮即可。

四、高级配置与优化技巧

1. 订阅功能的使用

对于拥有多个服务器或需要定期更新的用户，订阅功能是最高效的管理方式：

  1. 获取订阅链接（通常由服务商提供）
  2. 在Shadowrocket中进入"配置"→"订阅"
  3. 点击"添加订阅"
  4. 输入订阅名称和URL
  5. 设置自动更新频率（建议24小时）
  6. 点击"完成"保存

订阅成功后，所有服务器配置将自动同步到您的设备，并会定期更新。

2. 路由规则配置

Shadowrocket的强大之处在于其精细化的流量控制能力：

全局代理模式
- 所有流量都通过代理服务器
- 设置方法：进入"配置"→"全局路由"→选择"代理"

规则分流模式
- 根据规则智能分流，国内直连，国外走代理
- 设置方法：进入"配置"→"全局路由"→选择"配置"
- 可自定义规则或导入现成的规则集

自定义规则
高级用户可以创建自己的分流规则：
1. 进入"配置"→"本地文件"
2. 点击"+"创建新规则文件
3. 使用DOMAIN-SUFFIX、IP-CIDR等语法编写规则
4. 保存后在"全局路由"中选择该规则集

3. 性能优化设置

DNS设置
推荐使用可靠的DNS服务提升解析速度：
1. 进入"设置"→"DNS"
2. 添加8.8.8.8（Google DNS）或1.1.1.1（Cloudflare DNS）
3. 启用"DNS over HTTPS"增强安全性

延迟测试
定期测试服务器延迟有助于选择最优节点：
1. 长按服务器列表
2. 选择"测试所有服务器延迟"
3. 系统会显示各节点的响应时间

五、常见问题解决方案

1. 连接失败排查指南

问题现象：点击连接后无法建立链接，或很快断开
解决方案：
1. 检查服务器信息是否填写正确
2. 尝试更换加密方式（如从aes-256-gcm换为chacha20）
3. 检查本地网络是否正常
4. 联系服务商确认服务器状态

2. 速度慢优化建议

可能原因：
- 服务器负载高
- 本地网络状况差
- 协议或加密方式不合适

优化方法：
1. 尝试切换不同服务器节点
2. 更换为速度更快的协议（如从SSR换为Vmess）
3. 调整加密方式（轻量级加密如chacha20可能更快）
4. 检查是否开启了全局代理（不必要的国内流量也走代理）

3. 其他常见问题

问题：Shadowrocket频繁断开连接
解决：进入"设置"→"VPN"→启用"按需连接"和"重新连接"

问题：部分应用无法通过代理访问
解决：检查分流规则，可能需要为该应用添加单独的代理规则

六、安全使用建议

  1. 定期更新配置：特别是使用订阅服务时，确保配置保持最新
  2. 谨慎分享配置：避免将个人服务器信息随意分享，防止滥用
  3. 多重加密：对于高敏感活动，建议在代理基础上再使用TOR等工具
  4. 日志管理：定期清除应用日志，减少隐私泄露风险

FAQ

Matsuri 节点延迟排序功能如何使用？
Matsuri 会定期测速节点延迟，并结合策略组自动选择延迟最低节点。用户无需手动切换即可保持高速访问，优化网页、视频和游戏体验，提高网络稳定性。
VLESS + Reality 模式与 TLS 模式有何不同？
Reality 模式通过伪造握手和真实网站特征提升隐蔽性，TLS 模式侧重加密和传输效率。Reality 更难被 DPI 检测，适合高封锁环境，TLS 模式在稳定性和速度上更优。
WinXray 的 PAC 模式如何应用？
PAC 模式根据规则自动判断流量是否走代理，无需手动切换节点。适合访问国内外混合网站环境，提高网络访问速度和稳定性，减少误操作导致的访问失败。
Clash 订阅被墙或无法下载如何绕过？
若订阅源被直接屏蔽，可尝试先在境外服务器上用代理代理获取订阅并通过中转服务器公开一个新的链接；或者使用 HTTPS 与 CDN 中转、或将订阅以文件形式托管在不易被封的云存储上。
V2Ray 的 gRPC 模式适合哪些场景？
gRPC 支持多路复用和长连接，适合高并发访问和移动网络场景。相比 TCP 或 WebSocket，它可以减少握手次数，降低延迟，同时提高连接稳定性和吞吐量，特别适合游戏或即时通讯。
V2Ray 的 TLS 配置如何增强抗封锁能力？
TLS 配置可将流量伪装成正常 HTTPS 请求，隐藏真实数据特征。结合域名伪装、WebSocket 或 QUIC 等传输方式，可有效绕过封锁，提高节点长期可用性和连接稳定性。
Clash 的自动测速功能如何设置？
Clash 支持定期测速节点延迟，用户可以设置测速频率和超时时间。测速结果会影响策略组的节点选择，从而自动切换至最优节点，提高访问速度和连接稳定性。
VMess 的 WebSocket + TLS 配置有哪些好处？
WebSocket + TLS 可伪装为普通 HTTPS 流量，增强抗封锁能力和隐蔽性。结合域名伪装和策略组使用，可以在高封锁网络中保持稳定、高速和安全的网络访问体验。
Netch 如何结合策略组实现多节点优化？
Netch 可按应用和协议设置策略组，将流量分配到最优节点。结合节点延迟检测和自动切换功能，可提高网页浏览、视频播放和游戏访问速度及稳定性。
如何在路由器上使用 PassWall2 为不同设备设置不同策略？
在 PassWall2 的规则或策略组中为固定 IP 或 MAC 地址创建特定路由条目，将其映射到不同的策略组（如工作机走直连、游戏机走低延迟节点），并保存规则后重载以生效。
